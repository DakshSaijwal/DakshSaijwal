# Terminal profile card

`output.gif` (shown at the top of my profile) is generated by
[`terminal_card.py`](terminal_card.py) using
[x0rzavi/github-readme-terminal](https://github.com/x0rzavi/github-readme-terminal)
(`gifos`). It boots a retro terminal, logs in, runs `neofetch`, and reveals an
ASCII-art cat portrait beside my stats.

## Regenerate

```bash
python -m pip install --upgrade github-readme-terminal   # needs Python >= 3.9
# also install FFmpeg and make sure it's on PATH
python terminal_card.py                                   # writes output.gif
```

Edit the `STATS`, `ART`, colours, or timing in `terminal_card.py`, re-run, then
commit the new `output.gif`.

### Notes
- `gifos` supports 16-colour ANSI only, so the portrait is rendered as a
  high-contrast silhouette (`@%#*+=-` mapped to a few shades).
- On Windows, `gifos.gen_gif()` uses single-quoted paths that break under
  `cmd`, so `terminal_card.py` assembles the GIF with a direct FFmpeg call
  instead (edit the `FFMPEG` path near the top to match your install).
